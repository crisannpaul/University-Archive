# Algorithms for Data Science (Python)

- `battleship-solver/`: course project. A pygame battleship-solitaire puzzle with row and column clues, solved by a naive probability-distribution solver and by a backtracking solver; `tests.py` benchmarks the two and produces the accuracy and time plots. Slides: `Prezentare.pdf`.
- `knapsack/`: labs. Fractional, greedy and dynamic-programming knapsack with operation counting, then brute force vs meet-in-the-middle with timing. The `Profiler` class embedded in each file was provided by the course.

# Fitness gym database (SQL Server, T-SQL)

Database Administration course project (TUCN, year IV): a schema for gyms, members, subscriptions, trainers, classes and equipment (`create_db.sql`), with stored procedures, DML audit/history triggers, DDL triggers, an index, and logins and roles (`user.sql`). The report (Romanian) is the `.docx`.

The passwords in `user.sql` are lab placeholders.

# Fundamental Algorithms: analysis assignments (C++)

Eight assignments from the Fundamental Algorithms course (TUCN, year II). Each one implements the algorithms, counts assignments and comparisons while running them on growing inputs, and records my complexity conclusions in the header comment of `Source.cpp`. The charts next to the sources come from those runs.

1. Insertion, bubble and selection sort: best, average and worst case
2. Heap construction, bottom-up vs top-down
3. QuickSort, HeapSort, QuickSelect
4. Merging k sorted lists with a min-heap
5. Open-addressing hash table
6. Multi-way tree representations and pretty print
7. Dynamic order statistics tree (OS-select, OS-delete)
8. Disjoint sets and Kruskal

The sources include `Profiler.h`, the operation-counting header provided by the course. It is not mine and is not included here.

# Image Processing labs (C++, OpenCV)

Eleven lab solutions from the Image Processing course (TUCN, year III), one file per lab. The later labs cover morphological operations on binary images (7), statistical properties of grayscale images (8), spatial and frequency-domain filtering (9), noise modelling and filtering (10) and edge detection (11).

Each file is the `OpenCVApplication.cpp` of the course's Visual Studio / OpenCV 4.5.1 project template, which is not included (`common.h`, `stdafx.h`, the OpenCV binaries and the test images).

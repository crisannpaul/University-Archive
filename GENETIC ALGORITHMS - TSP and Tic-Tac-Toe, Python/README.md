# Genetic algorithms: TSP and tic-tac-toe (Python)

- `tsp/`: a genetic algorithm (tournament selection, elitism) for the travelling salesman problem, benchmarked against a greedy nearest-neighbour baseline on TSPLIB instances. `results/final_results_summary.txt` has the numbers and `plots/` the figures. Needs `tsplib95` and the TSPLIB instance files, which are not included.
- `tic-tac-toe/x0.py`: evolves a tic-tac-toe strategy with a genetic algorithm.

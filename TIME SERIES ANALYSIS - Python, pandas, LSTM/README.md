# Time series analysis (Python)

- `lottery-6-49-analysis/`: course project on Romanian Loto 6/49 draws. Number frequencies, even/odd distribution, the share of numbers above 31 in rolling windows before and after jackpot wins, and prize evolution.
- `labs/`: four notebooks. Decomposition of a climate series; stationarity tests, ACF and PACF; ML forecasting and classification on Beijing PM2.5; LSTM forecasting and anomaly detection on electricity load.

The larger lab datasets are not included.

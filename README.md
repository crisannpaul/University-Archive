# University Archive

Projects, assignments and lab work from my studies at the Technical University of Cluj-Napoca (TUCN): the four-year bachelor's degree in Computer Science (2020-2024) and the two-year master's that followed (2024-2026).

Each folder is one project and most have their own README. Build output, datasets, trained models and third-party libraries are left out, so some projects need those restored before they run.

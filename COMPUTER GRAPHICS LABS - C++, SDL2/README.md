# Computer Graphics labs (C++, SDL2)

Lab solutions from the Elements of Computer Graphics course (TUCN, year II), written on top of the SDL2 skeleton handed out by the course.

1. Vector and matrix library, 2D/3D transforms, polygons
2. Cohen-Sutherland line clipping
3. Bezier curves
4. Triangle rasterization with barycentric coordinates
5. Camera, projection and z-buffer for an OBJ viewer

My work is in the implementation files (`vec*.cpp`, `mat*.cpp`, `transform.cpp`, `polygon.cpp`, `clip.cpp`, `Bezier.cpp`, `rasterization.cpp`, `projection.cpp`, `zbuffer.cpp`). The headers, SDL main loops and test harnesses are course code. SDL2 itself, `tiny_obj_loader.h` and the test model are not included.

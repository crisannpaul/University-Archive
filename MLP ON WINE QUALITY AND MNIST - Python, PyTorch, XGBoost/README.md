# MLPs on Wine Quality and MNIST (Python, PyTorch)

Machine Learning course project (master's, year I): multilayer perceptrons (a basic one, and one with BatchNorm and Dropout) trained on Wine Quality and MNIST, with class-weight and SMOTE variants for the imbalanced wine classes and an XGBoost baseline. The report is `Documantatie ML.pdf`.

MNIST is not included.

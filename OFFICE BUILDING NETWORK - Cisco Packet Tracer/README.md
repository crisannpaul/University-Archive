# Office building network (Cisco Packet Tracer)

Network design project (TUCN, year IV): a three-floor commercial building with four VLANs and VTP, router-on-a-stick, a DHCP server, a DMZ with HTTP/FTP/DNS/mail servers, static routes, NAT towards a simulated ISP, SSH-only management and device hardening. The report (Romanian, with the IOS configurations) is the PDF; the `.pkt` opens in Packet Tracer.

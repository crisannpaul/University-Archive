# Data Structures and Algorithms labs (C)

Lab work from the first-year Data Structures and Algorithms course (TUCN): a generic `void*` data-structure library and the algorithm labs built on it.

- Labs 2-6: singly and doubly linked lists, dynamic array, stack, queue, binary tree, BST, chained hash table
- Labs 8-9: graphs on adjacency lists, using the queue and stack
- Lab 10: backtracking generator with function-pointer validators
- Lab 11: dynamic programming
- Lab 12: greedy
- Lab 13: binary search and merge sort

Each lab is a CMake project. The header files define the API given in the lab handout; the implementations are mine. Lab 3 is a work-in-progress snapshot and does not compile as-is.
